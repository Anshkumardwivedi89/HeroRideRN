# HeroRide — React Native / Expo Companion App

Cross-platform **React Native & Expo** companion application for **Hero MotoCorp smart digital clusters** (Hero Xoom 125 XTEC, Maestro Edge 125, Pleasure+ XTEC, Destini 125).

Recreates the native Android companion app ([`../HeroRide`](file:///e:/Hero%20Clone/HeroRide)) with **full support for physical iPhone device testing from Windows** using **Expo Development Builds (`expo-dev-client`)** and **EAS Build**.

---

## Key Features

1. **Scooter Cluster LCD Simulator:**
   - Real-time recreation of the Hero Xoom 125 LCD digital gauge.
   - High-contrast green backlit panel displaying turn arrows, countdown meters, live GPS speed (KM/H), and street name banners.
2. **Cluster Mirroring Test Suite:**
   - One-tap testing for all 17 cluster maneuver icons (`Straight`, `Right`, `Left`, `Slight`, `Sharp`, `U-Turn`, `Roundabout exits 1-6`, `Arrive`, `Recalculating`).
   - Push simulated Caller ID (`1<Name>~\n`), SMS alerts (`6<Sender>~\n`), and battery telemetry (`4<Batt>~<Bars>~4G~\n`).
3. **Filtered Bluetooth Low Energy Scanning:**
   - Automatically detects and badges Hero digital clusters (`HERO_`, `HMCL_`, `XOOM_`, `MAESTRO_`, etc.).
   - Signal strength (RSSI) monitoring and one-tap connect/disconnect.
   - Manual Bluetooth UUID / MAC address entry modal.
4. **GATT & Protocol Explorer:**
   - Inspect all discovered GATT services and characteristics on the scooter.
   - Send custom raw ASCII or Hex packets directly to cluster RX.
   - Live rolling terminal packet activity log.
5. **Background Telemetry Sync:**
   - Periodic heartbeat (every 15s/30s/60s) mirroring phone battery level and network status to the digital cluster gauge.

## Reverse-Engineered BLE Protocol Specifications

| Parameter | Specification |
|---|---|
| **Primary Service (Telit TIO)** | `0000FEFB-0000-1000-8000-00805F9B34FB` |
| **Cluster Write (RX)** | `00000001-0000-1000-8000-008025000000` |
| **Cluster Notify (TX)** | `00000002-0000-1000-8000-008025000000` |
| **Delimiter & Padding** | `~` (pads names to 14 chars, streets to 18 chars) |
| **Terminator** | `\n` (`0x0A`) |

### Example Packet Payloads
- Turn Right 500m on MG Road: `M02~500~MG Road~~~~~~~~~~~~\n`
- Clear Navigation: `M00~0~~~~~~~~~~~~~~~~~~~~\n`
- Incoming Call: `1John Doe~~~~~~~\n`
- SMS Alert: `6Mom~~~~~~~~~~~~\n`
- Phone Battery & Signal: `485~3~4G~\n`
- Call Ended: `7~0~d\n`
- Low Battery Alert: `30124\n`

## How to Test on a Real iPhone from Windows (No Mac Required)

Because standard Expo Go from the App Store cannot access native Bluetooth hardware or custom entitlements, this app uses an **Expo Development Build**. Expo compiles your custom client in the cloud via **EAS Build** and gives you a QR code to install it directly on your iPhone.

### Step 1: Install EAS CLI and Log In
In PowerShell on your Windows PC:
```bash
npm install -g eas-cli
eas login
```
*(If you don't have an Expo account yet, register for free at [expo.dev](https://expo.dev)).*

### Step 2: Configure EAS Build
Navigate to the project folder:
```bash
cd "e:\Hero Clone\HeroRideRN"
eas build:configure
```
*(Select iOS when prompted).*

### Step 3: Trigger the iOS Development Build
Run:
```bash
eas build --profile development --platform ios
```
- EAS will guide you through connecting your Apple ID (a free personal Apple account works!).
- It registers your test iPhone's UDID and generates a custom development `.ipa` in the cloud.

### Step 4: Install the App on Your iPhone
- Open your iPhone camera and scan the QR code generated by EAS (or open the install URL on your iPhone in Safari).
- Tap **Install**.
- On iOS 16/17+: Go to **Settings > Privacy & Security > Developer Mode** and ensure it is turned **ON** (requires restart).
- Go to **Settings > General > VPN & Device Management**, tap your developer certificate, and tap **Trust**.

### Step 5: Start Local Development
Once installed on your iPhone:
```bash
npx expo start
```
- Make sure your iPhone and Windows PC are connected to the same Wi-Fi network (or connect your iPhone via USB).
- Open the newly installed **HeroRide** app on your iPhone.
- Scan the Metro QR code shown in your Windows terminal.
- **You now have full access to native Bluetooth Low Energy hardware on your physical iPhone with Fast Refresh enabled!**

## App Architecture

```
HeroRideRN/
├── App.tsx                        # App entry point with BleProvider & Telemetry heartbeat
├── app.json                       # Config plugin with iOS Bluetooth permissions & background modes
├── eas.json                       # EAS Build profile for iOS development client
├── package.json                   # Dependencies (react-native-ble-plx, expo-location, etc.)
├── scripts/
│   └── verify-protocol.js         # Automated regression test for all cluster packet formats
└── src/
    ├── bluetooth/
    │   ├── BleContext.tsx         # React context & useBle() hook
    │   └── BleService.ts          # Central BLE manager with serialized FIFO write queue
    ├── components/
    │   ├── ClusterLcdPreview.tsx  # Authentic Hero Xoom 125 LCD gauge simulator
    │   ├── PacketLogView.tsx      # Terminal-style rolling BLE packet monitor
    │   └── ScooterCard.tsx        # Model status and connection card
    ├── navigation/
    │   └── RootNavigator.tsx      # 5-tab bottom navigation
    ├── protocol/
    │   ├── HeroClusterProtocol.ts # Byte-accurate packet encoders (M, 1, 2, 3, 4, 5, 6, 7, 9)
    │   └── types.ts               # ManeuverIcon, PacketLog, and BLE types
    ├── screens/
    │   ├── DashboardScreen.tsx    # Connection badge, quick status, cluster test suite
    │   ├── NavigationScreen.tsx   # Live TBT LCD preview, GPS speed, maneuver simulation
    │   ├── BluetoothScanScreen.tsx# Filtered Hero cluster scan, RSSI, pairing, manual MAC/UUID
    │   ├── GattExplorerScreen.tsx # Service/characteristic tree & raw packet sender
    │   └── SettingsScreen.tsx     # Heartbeat interval, auto-reconnect, diagnostic info
    ├── telemetry/
    │   └── TelemetryService.ts    # Battery & network telemetry heartbeat (30s interval)
    └── theme/
        └── colors.ts              # Hero Red (#E11924), Dark surfaces, LCD green
```
